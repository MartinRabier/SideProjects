## Jeu de la vie

Short code for "Le jeu de la vie" using pyplot to display the game. When a living particle has 2 or 3 alive neighbours it keeps living else it dies. When a dead particle has exactly 3 living neighbours it's brought to life. In other situations they keep the same state. Due to a bad vscode setup i'm forced to use a virtual environment runned as follows
```sh
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
Y
.\venv\Scripts\Activate.ps1
```
